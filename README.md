## 🚀 Deployment

Website ini bisa dideploy ke:
- **GitHub Pages**
- **Netlify**
- **Vercel**
- **Firebase Hosting**

### Quick Deploy ke GitHub Pages:

1. Upload repository ke GitHub
2. Go to Settings > Pages
3. Source: Deploy from a branch
4. Branch: main, folder: /(root)
5. Save
