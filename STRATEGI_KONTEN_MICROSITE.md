## 🚨 ANALISIS KEYWORD CANNIBALIZATION

### Keyword Overlap Analysis

#### **Awwnderful.com (Main Website)**
- **Primary Keywords**: 
  - "Sewa Photobooth Jakarta" (umum, brand-focused)
  - "Photobooth Indonesia" (nasional)
  - "Awwnderful Photobooth" (brand)

#### **Microsite Photobooth Jakarta**

  - "Photobooth Jakarta" (lokasi-specific)
  - "Sewa Photobooth Jakarta" ⚠️ **OVERLAP!**
  - "Photobooth Instant Print Jakarta"
  - "Photobooth Wedding Jakarta"

### ⚠️ POTENSI CANNIBALIZATION

**RISIKO TINGGI:**
1. ✅ "Sewa Photobooth Jakarta" - **SAMA PERSIS** dengan main site
2. ✅ "Photobooth Jakarta" - bisa overlap jika main site juga target ini
3. ✅ Service pages (Wedding, Corporate, Birthday) - bisa duplicate content

**RISIKO RENDAH:**
- "Photobooth Instant Print Jakarta" - lebih spesifik
- Long-tail keywords dengan lokasi spesifik
- FAQ content (informational intent)

## 🔒 ANTI-CANNIBALIZATION TACTICS

### 1. **Canonical & Internal Linking Strategy**

```html
<!-- Microsite -->
<link rel="canonical" href="https://photobooth-jakarta.com/">
<link rel="alternate" href="https://awwnderful.com/photobooth-jakarta" hreflang="id">

<!-- Main Site -->
<link rel="canonical" href="https://awwnderful.com/photobooth-jakarta">
```

**Internal Linking**:
- Microsite → Link ke main site untuk "Layanan Lain" (videobooth, 360, dll)
- Main Site → Link ke microsite untuk "Photobooth Jakarta Instant Print"

| Keyword | Main Site | Microsite |

| Sewa Photobooth Jakarta | ✅ Primary | ❌ HINDARI |

## ✅ REKOMENDASI IMPLEMENTASI HIGH PRIORITY (NO CANNIBALIZATION)

### 1. **Mobile Menu** ✅ SAFE
- Tidak ada risiko cannibalization
- Pure UX improvement

### 2. **WhatsApp Button** ✅ SAFE
- Conversion tool, bukan content
- Tidak ada keyword overlap

### 3. **More Testimonials** ✅ SAFE (dengan syarat)
- **SAFE jika**: Jakarta-specific testimonials
- **RISK jika**: Generic testimonials (sama dengan main site)
- **Action**: Fokus testimoni dari klien Jakarta dengan detail lokasi

### 4. **Pricing Section** ⚠️ NEEDS CAREFUL HANDLING
- **RISK**: Bisa duplicate dengan main site
- **SAFE jika**: 
  - Jakarta-specific pricing (dengan delivery cost)
  - Instant print package pricing (niche)
  - Area-based pricing (Jakarta Pusat vs Depok)
- **Action**: Buat pricing yang berbeda angle (package-based, bukan service-based)

### 5. **FAQ Section** ✅ SAFE
- **SAFE karena**: 
  - Informational intent (tidak transactional)
  - Jakarta-specific questions
  - Long-tail keywords
  - Tidak compete dengan main site (yang lebih brand-focused)
